# nanoclm

A minimal project for learning how Contrastive Language Models work.

The intended starting point is a frozen language encoder with small trainable
state and action projection heads, followed by contrastive training and evaluation.

Repository initialization only. Implementation will follow.

Inspired by the [CLM article](https://contrastive-lm.notion.site/) and
[reference repository](https://github.com/Contrastive-LM/CLM).
